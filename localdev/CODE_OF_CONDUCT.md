# Code Of Conduct

## Our Standard

This repository expects respectful, technically grounded collaboration. Contributors should:

- communicate clearly and in good faith
- focus criticism on code, design, and evidence
- make room for different experience levels and backgrounds
- treat security, privacy, and user safety as first-class concerns

## Unacceptable Behavior

The following behavior is not acceptable in project spaces:

- harassment, threats, insults, or discrimination
- deliberate intimidation or bad-faith derailment
- publishing private information without permission
- encouraging unsafe wallet behavior or secret handling
- spamming, trolling, or repeated low-signal disruption

## Enforcement

Project maintainers may edit, remove, or reject comments, issues, pull requests, and other contributions that violate this policy. Repeated or severe violations can result in temporary or permanent bans from project spaces.

## Reporting

For conduct concerns, contact `support@metayoshi.app`.

For security issues, use `security@metayoshi.app` instead of public channels.
