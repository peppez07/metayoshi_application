# Support

## Where To Ask

Use the channel that matches the problem:

- GitHub Issues: reproducible bugs, documentation fixes, feature requests, and build problems in the public repository
- `support@metayoshi.app`: account-independent product questions, setup help, and user support
- `security@metayoshi.app`: vulnerabilities, permission bypasses, signing issues, secret exposure, or other security-sensitive reports

## Before Opening An Issue

- confirm the problem still exists on the latest local checkout
- include the exact browser and extension build you tested
- include the network, asset, and reproduction steps
- redact secrets, wallet passwords, seed phrases, and private keys

## What Not To Share Publicly

Never post:

- seed phrases
- private keys
- live bridge credentials
- API secrets
- unredacted personal wallet data
